Exam management platform

A solution that implements a Student Information System (SIS) that streamlines the management of student data, subjects, grading, and attendance in large schools. Key features include attendance tracking, grade management, and role-based access for administrators, teachers, students, and parents.

Problem

Managing student data especially in a large school , including different subjects, grading and attendance is complex and prone to error. Without a proper system it might lead to data entry errors and reporting errors.

Solution

The goal is to create an integrated platform that allows teachers, administrators, class teachers, and parents to efficiently capture, view, and manage student data. The system will:

  • Streamline data entry
  • Facilitate performance tracking
  • Generate reports

My design process

User research: summary

From the data provided, I reviewed students marks across various forms, terms, and streams, which were managed in Excel spreadsheets. Based on this, I identified a clear need for an Examination Management System to improve data handling and streamline the process.

To define the key users, I targeted the following personas:

  • Teachers: Responsible for teaching, setting exams, and entering student marks.
  • Class Teachers: Oversee the academic performance of entire classes.
  • School Administrators: Manage student data, subjects, and overall system configurations.
  • Parents/Guardians: Track student progress and performance.

These personas were selected based on their roles in the academic process and their interaction with student data.

Assumptions

  • Teachers are responsible for inputting data: Teachers will regularly input scores, grades, and attendance for their assigned subjects and students.
  • Class teachers oversee the performance: Class teachers will monitor the overall performance and data submission across all subjects within their assigned class/stream.
  • Administrators manage the system: Administrators will have full control over managing users, assigning subjects, setting up classes/streams, and generating school-wide reports.
  • Parents have view-only access: Parents or guardians can view their child's performance but cannot modify any data.
  • The system integrates role-based access: Different users (teachers, class teachers, administrators, parents) have distinct access levels and can view or modify data accordingly

User journey

Teachers journey

Goal: Input student marks and view class performance.

  1. Login → Dashboard → Selects Class/Stream and Subject → Inputs Marks for each Student → Submits Data.
  2. Scenario 1 (Marking Exams): Teacher logs in, selects the form and subject, inputs scores for each student, and submits.
  3. Scenario 2 (View Performance): Teacher logs in, selects a class, and views student performance reports, identifying struggling students.

Administrators journey

Goal:Manage data integrity and generate reports.

  1. Login → Dashboard → Manage Teachers, Students, and Subjects → Generate Reports → Export Data for Analysis.

Parent/Guardian journey

Goal:View child’s performance and receive updates.

  1. Login → Dashboard → View Child’s Grades and Attendance → Print Report.
